# Research Casebook

The public `/casebook` index and three detail pages provide complete authored
research walkthroughs. They complement the decision-based learning labs with a
question, observable criterion, trusted task, exact baseline/variant inputs,
fixed task context, authored replies/action records and explicit claim limits.

All records are independently invented fixtures. The origin notice remains
visible on every page and downloadable note. No real model or tool is run, no
live challenge finding is reproduced, and no success rate is claimed.

## Cases

- **A label is not authority:** an inventory card claims permission to change a
  count. A source label cannot grant authority; the fixture illustrates the
  stated factual-integrity criterion.
- **A reply is not an effect:** a booking draft has a polite reply but a proposed
  confirmation and unknown completion. The proposal is a concern; the record
  does not establish a completed booking.
- **A criterion is a contract:** one-line formatting loses itinerary details.
  Formatting and task fidelity need separate checks.

Known setup values are inspectable. Actual model versions/settings remain
unknown because these are authored records. Identical missing fields do not
verify matched real conditions. Primary sources inform the method; they do not
verify fictional replies or actions.

## Boundaries

The immutable catalog is separate from Workbench `Attempt` and `Experiment`.
Native **Plan a follow-up** opens a new private Workbench with no query, fixture
input or results transferred. It does not save, unlock, prepare or execute an
experiment. Enter actual scope and observations through the existing workflow.

The allowlisted `/casebook/[caseId]/note` GET returns only a deterministic public
Markdown teaching note with its fictional provenance. It never reads page
state, vault records, request-body evidence, accounts or cloud snapshots.
Unsupported identifiers return a generic 404. It is not a research restore
backup. Notes and all reading/disclosure actions work without JavaScript.

Unknown Casebook and Lab detail identifiers are rejected through a shared
closed-catalog routing guard. The recovery rewrite preserves HTTP 404, forwards
the ordinary per-request nonce and CSP, and serves a readable branded page
without relying on client error recovery. Notes, APIs, auth and the private
Workbench route retain their original handling. Recovery links never reflect
the requested identifier or query.

Keep live challenge details private until at least 30 full days after the actual
confirmed end. Unknown/unconfirmed ends remain restricted. No date automatically
publishes research. Public authored fixtures remain separate from this private
research process.

## Mobile polish

Editable text fields use 16px on mobile to avoid focus zoom on iOS. Prompt
Studio's known-conditions disclosure has at least a 44px target. These changes
retain the Signal typography, square controls, theme colours and exact evidence
handling; no schema, database migration or external service is added.
